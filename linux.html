🐧 Linux - Ubuntu/Debian🟢 Đang hoạt động
⚠️ Lưu Ý: Một số lệnh cần quyền sudo. Nhập mật khẩu hệ thống khi được yêu cầu.

📋 Yêu Cầu

  • Ubuntu 18.04+ hoặc Debian 9+
  • Python 3.7+ và quyền sudo
  • Kết nối Internet ổn định

🚀 Lệnh Setup

Bước 1 — Cập nhật hệ thống

sudo apt update && sudo apt upgrade -y

Bước 2 — Cài Python & công cụ

sudo apt install -y python3 python3-pip git wget curl

Bước 3 — Cài thư viện Python

pip3 install requests beautifulsoup4 pysocks faker pystyle colorama urllib3

Bước 4 — Chạy Tool

cd ~/Downloads && python3 spamsms.py

✅ Thành công khi thấy giao diện tool hiện ra

🔄 Cách Khởi Chạy Tool Lần Tiếp Theo

cd ~/Downloads && python3 spamsms.py

Hoặc thay đường dẫn bằng vị trí thực tế của tool

🔧 Xử Lý Sự Cố Thường Gặp

❌ Lỗi: "command not found: python3"

Python3 chưa được cài đặt. Hãy chạy:

sudo apt install -y python3

❌ Lỗi: "pip3: command not found"

Pip3 chưa được cài đặt:

sudo apt install -y python3-pip

❌ Lỗi: "ModuleNotFoundError"

Thư viện Python chưa được cài đặt. Chạy lệnh cài đặt pip ở bước 3 lại:

pip3 install requests beautifulsoup4 pysocks faker pystyle colorama urllib3

❌ Lỗi: "Permission denied"

Bạn có thể không có quyền truy cập file. Thử chạy với sudo hoặc thay đổi quyền file:

chmod +x spamsms.py && python3 spamsms.py

💡 Mẹo Hữu Ích

Sử dụng Virtual Environment

Để tránh xung đột thư viện:

python3 -m venv myenv source myenv/bin/activate pip install requests beautifulsoup4 pysocks faker pystyle colorama urllib3

Tạo Shortcut để chạy nhanh

echo "cd ~/Downloads && python3 spamsms.py" > ~/runtool.sh chmod +x ~/runtool.sh ~/runtool.sh

📚 Lệnh Hữu Ích Khác

  • Kiểm tra phiên bản Python: python3 --version
  • Kiểm tra phiên bản pip: pip3 --version
  • Liệt kê thư viện đã cài: pip3 list
  • Cập nhật pip: pip3 install --upgrade pip
  • Xóa tool: rm -rf ~/Downloads/spamsms.py
